# waterlevel-feed
Scrapes public water level data source and creates RSS feed with Github Actions

The quarter-hourly data is updated ca. one hour after the point in time. So 11:15 is updated with the value of 11:15 at the point in time 12:15.

Das Urheberecht liegt bei den unter (3) genannten Stellen.
https://www.pegelonline.wsv.de/gast/nutzungsbedingungen
Dieser Scraper verändert die Inhalte nicht.
